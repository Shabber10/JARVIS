# 🤖 JARVIS — Autonomous Multilingual Desktop AI Assistant

> **"Hello Boss! System is online now."**  
> An all-powerful, autonomous voice assistant with full laptop control, continuous hands-free wake-word detection, multi-language support (English 🇬🇧, Telugu 🇮🇳, Hindi 🇮🇳), and offline intelligence.

---

## 🖥️ Siri / Gemini Floating HUD Overlay

Jarvis now includes a sleek, modern, dark-themed floating HUD overlay widget that automatically displays on your screen whenever Jarvis is listening, processing, or speaking:
* 🎙️ **Animated Siri/Gemini Orb**: Pulsing ripple waves when listening, orbiting aura when thinking, and dynamic waveforms when speaking.
* 💬 **Real-Time Subtitles & Transcription**: Instant preview of your spoken directives and Jarvis's replies.
* 🎙️ **Microphone Button (`🎙️`)**: Tap to activate Push-to-Talk or trigger direct speech listening immediately.
* ⏸️ **Stop Button (`⏸`)**: Instantly halt active speech playback or interrupt long responses.
* 📞 **Hangup / Power Off Button (`📞`)**: Permanently turn off / shut down Jarvis safely with clean process exit.
* 🖱️ **Draggable & Always-on-Top**: Smoothly reposition the floating card anywhere on your desktop.

## ⚡ Quick Control Scripts

| Script / Launcher | Action |
| :--- | :--- |
| 🚀 **`Launch_Jarvis.vbs`** | **Primary 1-Click Launcher** — Starts Jarvis silently with the Siri/Gemini Floating HUD (Zero terminal windows). |
| 📌 **`Create_Desktop_Shortcut.vbs`** | Places a **"JARVIS AI"** shortcut icon directly on your Windows Desktop. |
| 🔴 **`stop_jarvis.bat`** | Cleanly terminates all running Jarvis processes in 1 second. |
| ⚙️ **`enable_autostart.bat`** | Configures Jarvis to launch silently whenever your computer boots up. |
| ❌ **`disable_autostart.bat`** | Removes Jarvis from Windows Startup. |
| 💻 **`run_jarvis.bat`** | Launches Jarvis in visual Developer Terminal mode. |
